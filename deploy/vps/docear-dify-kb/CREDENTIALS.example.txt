Docear Dify KB Gateway
======================
Public base URL (for Dify API Endpoint): https://webchat.mantoublog.top/dify-kb
Retrieval URL (auto): https://webchat.mantoublog.top/dify-kb/retrieval
Health: https://webchat.mantoublog.top/dify-kb/health

Dify 外部知识库 API Key (Bearer): <see secrets.local/docear-dify-kb.CREDENTIALS.txt on maintainer machine>

External Knowledge ID 可选值:
  mindmaps   - 全库搜索（默认）
  memory     - 仅 Cursor 长期记忆 memory/
  cursor     - 仅 01Cursor 目录
  no-daily   - 排除 daily 对话存档
  path:相对路径 - 例如 path:02目标发展/07创作达人
