Twigmark

本地优先的桌面思维导图与个人知识工作台。把想法、任务、专注与 AI 协作收进同一套本机导图。

获取最新版 查看源码

当前版本 1.2.0 stable

做什么用

导图仍是主角；提醒、番茄、报表与 MCP 把日常工作流补齐——数据默认留在本机。

  • 思维导图与工作区

    完整桌面导图编辑，本地项目与多文档工作流。

  • 效率与时间

    提醒待办、安排中心、番茄钟、报表与剪切板历史。

  • AI 可接入

    本机 MCP，让 Cursor 等助手读写导图；无强制云账号。

  • 知识组织

    标签分组、收藏、关系图谱；可选文献与 Draw.io。
