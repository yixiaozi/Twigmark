About

介绍

Twigmark 由 Mantou（馒头）维护。基于 Freeplane / Docear（GPL），面向日常整理与 AI 协作，而不是云端学术套件。

解决什么问题

把想法、任务、文献线索、专注记录和 AI 读写，收进同一套本地导图。

  • 导图仍是主角：节点、链接、图标、折叠、样式
  • 工作流补齐：提醒、待办、番茄、报表、剪切板历史
  • AI 可接入：本机 MCP，Cursor 等助手读写导图
  • 不依赖 docear.org；没有强制账号与云同步

适合个人知识库、项目规划、学习笔记、日常待办与「第二大脑」式整理。

为什么快

  • 本地启动：数据在本机目录，不先过云端登录墙
  • 文件即真相：.mm 可备份、可 Git、可随身拷
  • MCP 即插：本机端口对接助手，少一层中转
  • 按需加载：报表等 Tab 先开后载，少卡主界面

三分钟上手

  1. 解压便携包（或安装包），运行启动器（文件名可能仍是 docear.exe）。
  2. 首次选择主目录（导图与数据放这里）。
  3. 欢迎图里：Insert 新建子节点，Enter 编辑，Ctrl+S 保存。
  4. 之后可用「帮助 → 教程」再打开上手图。

运行环境

  • Java 8（JRE / JDK）
  • Draw.io 需要 JavaFX（打包脚本可注入）
  • 可选：Cursor（MCP）、Git、Todoist 等
  • 当前主要发行目标：Windows（亦有 Mac 构建路径）
